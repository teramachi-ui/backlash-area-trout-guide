# BACKLASH Area Trout Field Guide

BACKLASHスタッフが訪れたエリアトラウト管理釣り場を、地域や釣り場名から探せるフィールドガイドです。

## Live Site

https://backlash-area-trout-guide-teramachi.vercel.app/

## Features

- 地域タブとキーワード検索
- 各釣り場の現地写真または雰囲気イメージ
- 各施設の公式サイトへのリンク
- スマートフォンとデスクトップに対応したレスポンシブ表示
- 掲載数の増減に自動対応する一覧件数

## Development

```bash
pnpm install
pnpm run dev
```

## Verification
